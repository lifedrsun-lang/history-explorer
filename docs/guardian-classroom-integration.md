# 3차 연결 상태
- 하늘빛초/새솔초 기존 통합 입장 화면에서 정상 학생 비밀번호는 기존대로 처리하고, 보호자 학교 코드는 서버 검증 후 자녀별 보호자 인증 화면으로 분기.
- 보호자 UI: 별도 세션, 준비물/추가 안내/과제 알림/동·은엽전, 12회차 및 사전 불참 등록·취소·수정. 출석 원본 미확인 상태는 미확인으로 표시.
- 기존 StudentCard에 불참 건수 칩 추가, 서버 조회 및 확인 처리. 기존 레이아웃 변경 없음.
- 운영 활성화 전 필요: 실제 Firestore 규칙 확인, 교사 UID 설정, 12회차 일정 입력 및 실제 출석 소스 검증, 교사용 학교 설정/코드 발급 화면, 나머지 학교 입장 분기, 빌드 및 테스트. GUARDIAN_CLASSROOM_ENABLED 기본 비활성.
- 알려진 제한: 기존 학생용 입장 화면 자체의 학생명 검색 및 로컬 저장 구조는 유지함. 보호자 인증 전에는 신규 보호자 API가 자녀 정보나 사유를 반환하지 않음. 현재 소스의 기존 학생 정보 노출 범위는 별도 검토 대상.
