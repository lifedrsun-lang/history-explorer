# 2차 한국사 참고문헌 검증·출처별 보기 분류 정리 (2026-11-06)

## 사용자 요청
기존 「✅ 누락 검증 추가 사건 / ✅ 참고문헌 대조로 추가한 사건」은 역사 학습용 출처 분류가 아니라 검증 작업 단계이므로 화면에서 제거한다. 새로 추가한 사건은 실제 참고한 책의 표시 항목에 포함한다. 인물·제도·문화유산 2차 대조를 계속한다. **한능검 기출문제·연동 코드는 수정하지 않는다.**

## 화면 변경 및 보존 기준
- 제거: `✅ 누락 검증 추가 사건` 체크박스, `✅ 참고문헌 대조로 추가한 사건` 배지, `📖 누락 검증으로 보완한 시대 흐름` 문구.
- 유지: `별별한국사 · 기본`, `별별한국사 · 심화`, `용선생 교과서 한국사`의 체크박스, 기존 기출·문화유산 체크박스, 기존 사건·학생 권한.
- 새로 표시: `로빈의 한국사`, `한국사 읽기책` (독립 참고문헌별 체크박스).
- 기존 '검증 추가 사건' **15개**의 실제 자료별 재분류:
  - 『한 권으로 끝내는 로빈의 한국사』 사건 **11개**
  - 『한국사 읽기책』 사건 **3개**
  - 『용선생 교과서 한국사 1』 자격루 사건 **1개**
- 분류는 코드의 `phaseOneEvidence.book` 원천 필드에 근거함. 임의 추측 없이 세 가지 출처가 식별되지 않으면 표시하지 않음.
- 참조 출처·PDF 쪽수는 카드 내 접기·펼치기 내용에 유지. 검증 추가 경위는 코드와 이 문서에 기록.
- 이들 카드는 이미 보충자료 전용 API의 학생별 접근 권한 검사를 거쳐 제공되며, 화면 체크는 **자료 표시만** 제어함. 기존 권한 확장은 하지 않음.
- 기존 핵심 연표 및 한능검 문제 연결을 위한 사건 ID 변경 없음.
