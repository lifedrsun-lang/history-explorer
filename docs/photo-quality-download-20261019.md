# 학생 사진 화질 및 사진별 다운로드 제한 — 2026-10-19

## 요청과 구현

- 학생 계정별로 사진 한 장당 다운로드 3회. 앨범 전체 3회가 아니다.
- 학생 열람 자체에는 횟수 제한을 두지 않는다. 선랩 다운로드 버튼/API가 파일을 제공하는 횟수만 제한한다. 화면 캡처·이미 전달된 이미지의 복사까지 차단하는 DRM이 아니다.
- 다운로드 횟수는 `(photo_id, student_key)` PK로 서버 DB에 보관한다. 재로그인·새로고침·기기 변경으로 초기화되지 않는다.
- `claim_student_photo_download`의 조건부 INSERT ON CONFLICT UPDATE로 여러 탭/기기의 동시 요청도 3회까지만 허용한다. 브라우저의 카운터나 요청 본문의 studentKey는 신뢰하지 않는다.
- 앨범 상세 응답에는 본인에게 해당하는 사진별 남은 횟수만 반환한다.
- 다운로드는 학생 세션, 사진 인증, 실제 연결 명부/분기, 공개 상태/기간, 현재 동의 상태를 확인한 후 처리한다. 원본에서 이미지를 준비하고 다시 권한을 확인한 뒤 횟수를 차감하며, 응답 직전에도 재검증한다.
- 원본 조회·이미지 변환·DB 기록 실패 전에는 파일을 제공하지 않는다. 차감 뒤 권한이 바뀌거나 전송이 중단된 경우에는 횟수가 차감될 수 있다. 브라우저/OS의 최종 저장 성공은 서버에서 증명할 수 없으며 화면에 이를 안내한다.

## 화질

기존 업로드 코드는 화면용 이미지를 최대 2200×2200 WebP 품질 설정86으로 생성했다. 주변 작은 사진은 360×300 품질72였다. 선택 시 화면용 이미지를 읽는 것을 코드에서 확인했다. 실제 사용자가 본 이미지의 픽셀 비교나 육안 개선 검증은 이번 작업에서 하지 않았다.

새 확대 응답은 기존 축소본을 재압축하지 않고 보존된 원본을 읽어 최대3840×3840, 품질95(전송 크기 초과 시92) WebP로 생성한다. 작은 주변 사진은 유지한다. 선택된 사진의 CSS 크기도 실제 확대 크기로 지정해 작은 카드의 transform 배율만 키우는 방식을 보완했다.

다운로드는 원본 픽셀 크기를 유지한 JPEG다. 자동 방향 회전, EXIF/GPS 제거 후 품질98→95→92 순서로 4,000,000바이트 이하인지 확인한다. 이 범위에서도 초과하면413이며 횟수를 차감하지 않는다. 관리자 원본은 수정하지 않는다. 원본 자체가 저해상도이면 없는 세부 정보를 복구하지 못한다.

개인 보관용 다운로드, 사진당3회, 저장한 파일은 열람 종료 후 자동 회수되지 않는다는 안내를 추가했다. 안내문 버전은 `2026-10-19.v2`이며 기존 동의가 있으면 재확인된다.
