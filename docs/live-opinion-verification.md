# Sun Lab 실시간 의견 모으기 — 검증 기록

2026-10-12~13 (한국시간). 기능 브랜치: `feat/live-opinion-20261012`.
구현 커밋: `6927f23c4df54917be51f3ccabbff0b807f3071a`.

## 구현

- 관리자: `/teacher/opinion`. 관리자 홈의 기존 카드 렌더러에 독립 카드 추가.
- 학생: `/opinion`. 로그인 없이 서명된 HttpOnly 브라우저 쿠키로 참여.
- Firebase 교사 인증, 기존 Supabase 서버 전용 연결 재사용.
- Supabase `opinion_activity` 한 행에 주제·안내·회차·현재 답변 보관.
- 모든 변경은 `opinion_mutate`의 행 잠금으로 순서 보장. 리셋 시 활동 종료·회차 무효화·답변 제거.
- 한 브라우저당 한 의견. 삭제 후에는 문장 없는 제출 표시만 현재 회차 종료까지 남김.
- 참여 인원은 이번 회차에 제출한 고유 브라우저 수. 삭제한 의견의 제출자도 포함.
- 1초 간격 순차 polling. 백그라운드 탭은 4초 간격, 복귀·재연결 시 즉시 갱신.
- 16:9 보드, 실제 DOM 카드 크기 측정, 중앙 주제 회피, MaxRects 배치, 공간 부족 시 목록 보기.
- React 텍스트 노드 출력으로 HTML 실행 방지. 모션 감소 설정 지원.
