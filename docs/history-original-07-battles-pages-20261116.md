## 직접 확인한 내용

교재 39쪽 「당나라를 몰아내고, 세 나라를 하나로」의 본문에는
675년 매소성 전투에서 신라가 당나라 군대를 물리친 내용과,
이듬해(676년) 기벌포에서 당나라 수군을 상대로 승리한 내용이 모두 나온다.

- `supplement-flow-silla-gibeolpo-676`

## 수정

- 두 사건 모두 `sourceIssueNumbers: [7,8]`로 변경
- 정확히 확인한 『별꼼역사』 07호 본문 39쪽(PDF 41쪽) 출처 추가
- 기존 08호 연결과 '08호 원본 쪽수 미확인' 상태는 검증 전까지 보존
- 수강 완료 06호에는 두 사건이 보이지 않아야 함
- 역사 사건 ID를 새로 만들거나 사건을 복제하지 않음
- 참고서 전용 추가 사건이 아니라 교재 기반 일반 연표로 노출
