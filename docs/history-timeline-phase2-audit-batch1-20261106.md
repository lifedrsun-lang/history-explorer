## 검증 방식
업로드 PDF의 실제 페이지 이미지를 직접 열어 읽은 뒤, 현재 Sun Lab의 기본 사건·별별한국사 기존 보충·용선생 기존 보충을 코드에서 대조했다. 사건이 이미 존재하면 원문을 인용하지 않고 **기존 카드의 보충 설명**을 새로 작성한다. 정확한 개시 연도가 있는 중요한 문화사 사건만 독립 카드로 생성한다. 책의 인쇄 쪽수와 PDF 페이지 번호(+2인 용선생)를 혼동하지 않는다.

- 연도 교차 검증: [국사편찬위원회 우리역사넷 자격루](https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_r300785), [국가유산청](https://digital.khs.go.kr/heri/heriDetail.do?ctptUid=13898859666590200076)
- 구분: 1433년 무렵 완성과 **1434년 공식 사용**, 현재 남아 있는 물통이 1536년 다시 제작된 것임을 구분.
- 일반 연표·기출문제 데이터에는 합치지 않고 기존 「✅ 누락 검증 추가 사건」 자료 표시 선택 아래 제공.

## 검사 원칙과 미완료
- 새로운 코드 등록: 기존 사건 설명 **12개 주제**, 신규 연도 카드 **1개**
- 제시한 수치는 **실제로 추가한 주제/카드의 개수**이며 전권 누락의 총개수가 아니다.
- 학생 정보, 수강 완료 호수, 역사 원본 사건 데이터, 한능검 문제은행, 한능검 시험회차·연표 기출 연결 파일을 변경하지 않는다.
- 기존 별별한국사 열람권한 확인이 통과한 사용자에게만 위 내용이 전달되며, 표시 필터에 따라 화면이 결정된다.
- 2차 완료로 판정하려면 **8권의 모든 해당 주제·본문·사진 캡션·사료와 기존 사건 ID를 일대일로 대조한 검증 표**가 필요하다.
- 실명 계정으로 교사/학생 화면의 공개 범위 검증 전에는 운영 배포를 보류한다.
