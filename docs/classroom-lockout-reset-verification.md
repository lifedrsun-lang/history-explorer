# 교사 학급 10분 잠금 해제

## 동작
- 출강관리 → 학교 → 반 카드의 **10분 잠금 해제** 버튼.
- 몬스터 비밀번호를 3번 틀려 생긴 브라우저의 10분 대기를 해당 반 단위로 해제한다.
- 해당 반에서 잠긴 모든 기기에 적용한다. 학생 번호를 선택하기 전 발생하는 잠금이므로 학생 개인을 식별하거나 잠금 인원수를 표시하지 않는다.
- 학생은 몬스터 비밀번호를 다시 선택한다. 비밀번호를 생략하거나 계정 비밀번호를 변경하지 않는다.
- 이미 열린 화면은 업데이트된 코드를 새로고침한 뒤 이용한다. 잠긴 화면에서만 15초 간격으로 해제 상태를 확인하며, 화면이 숨겨지거나 오프라인이면 정기 조회를 중단한다. 수동 확인 버튼도 제공한다.
- 신호는 별도 Firestore 문서 `classroom_lockout_resets/{schoolSlug}__{grade-class}`에 저장한다. 학교 설정 저장·기존 계정·수강생·차시 데이터에 쓰지 않는다.
- POST는 기존 교사 Firebase 인증 검증을 사용하며, 학교와 반 존재 여부를 확인한다. 공개 GET은 해제 시각과 서버 현재 시각만 반환한다.

## 로컬 검증 결과
- `npm run build`: 통과 (Next.js 16.2.6 전체 빌드).
- `npx tsc --noEmit`: 통과.
- 신규 파일 ESLint: 통과.
- `git diff --check`: 통과.
- `NODE_PATH=/tmp/sunlab-lockout-test/node_modules node scripts/verify-classroom-lockout-reset.mjs`: 10개 계약 검증 통과.

계약 검증: 미인증/잘못된 학급 요청 차단, 저장 실패 처리, 기기 시계 오차 및 이전 신호 재사용 방지, 교사 UI→API→격리 저장소→학생 UI 연결, 다른 반 유지, 재렌더 시 조회 증가 방지, 공개 응답의 교사 ID 미노출, 네트워크 실패 시 잠금 유지, 이전 잠금/다른 반의 늦은 응답 무시, 숨겨진 탭 조회 중지.

Firebase 인증·Firestore는 격리된 테스트 어댑터를 사용했다. 위 결과는 실제 배포 환경의 로그인 및 DB 쓰기까지 검증했다는 의미가 아니다. 실제 운영 학생에게 일부러 잠금을 발생시키거나 실제 학급의 잠금을 해제하는 테스트는 수행하지 않았다.

테스트용 패키지는 앱 의존성에 추가하지 않는다. `@testing-library/react@16.3.0`, `jsdom@26.1.0`, `react@19.2.4`, `react-dom@19.2.4`를 별도 디렉터리에 설치하고 NODE_PATH를 지정한다.
