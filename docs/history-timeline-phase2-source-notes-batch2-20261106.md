## 작업 목적
사용자 업로드 역사서의 인물·제도·문화유산·사료 가운데 기존 연표 사건에 설명이 부족한 부분을 보완한다. 별도 검증 체크박스는 만들지 않고 **자료별 표시 설정**(용선생·로빈의 한국사·한국사 읽기책)을 사용한다. 학습자료 원문은 복제하지 않으며 정확한 책 이름과 PDF/인쇄 쪽수만 기재한다. 기존 학생 데이터, 한국사 01~23호 원본 사건, 한능검 문제은행, 시험 문제 연결은 변경하지 않는다.

- 구석기·신석기 도구(별별한국사 기본 PDF 15쪽)는 기존 신석기 가락바퀴·뼈바늘 보충 설명과 겹치므로 신규 카드로 중복 등록하지 않았다.
- 별별한국사 심화 상 PDF 59쪽의 백제 문화와 정치, 심화 상 PDF 103쪽의 고려 문화유산 사진 자료는 내용 분류 후보이지만 세부 유물명·연표 연결은 추가 확인 대상으로 남긴다.
- 별별한국사 심화 하 PDF 18쪽의 조선 후기 실학·경제 문제는 기존 수업 주제와 대조가 더 필요해 이번 배치 신규 등록을 보류했다.
- 초등·읽기책 자료도 일부 페이지를 직접 확인했지만 **전권 본문·캡션·사료 검토 완료로 판정하지 않는다**.

## 기능 점검
1. 신규 설명 12개가 실제 기존 사건 ID에 연결되는지 확인.
2. 로빈/읽기책 자료는 각 출처별 체크박스를 따르며 다른 책 분류에 섞이지 않음.
3. 학생은 기존 완강 호수·보충자료 권한의 공통 검사 후에만 내용을 수신.
4. 기존 1·2차 카드와 한능검 문제은행·기출 링크 데이터 미변경.
5. Vercel Preview 빌드/TypeScript 검사 및 Production 상태 확인 전에는 배포 완료로 기록하지 않음.

**남은 2차 검증:** 8권 전체의 인물·제도·문화·사료와 사진 설명을 페이지별로 대조하고 미처리 항목을 없애는 작업. '검증 2차 완료' 또는 '누락 0건'으로 선언할 수 없음.
