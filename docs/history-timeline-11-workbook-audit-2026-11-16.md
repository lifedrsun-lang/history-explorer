# 별꼼역사 한국사 연표 — 11호 워크북 인물 대조 (2026-11-16)

## 출처·검사 범위
- 실제 열람 자료: `11호 전쟁을 이겨냔 백성들 고려_워크북.pdf`, 표지에는 **「전쟁을 이겨낸 백성들 고려 2」(워크북 11)**로 기재.
- 워크북 **인쇄 쪽수 6~30쪽**의 해당 인물 및 활동을 확인. 이 파일은 **11호 본권이 아니므로 본권 원문 전수대조가 아님**.
- 현재 운영 코드: `lib/historyTimelinePeople.ts`, `lib/historyTimelineGoryeo.ts`, `lib/historyTimelineAllTopics.ts`와 비교.
- 출처에 표시되지 않은 인물 생애·날짜는 임의 추가하지 않음. `강민첨`의 일반 역사 역할은 한국학중앙연구원 「강민첨」(https://encykorea.aks.ac.kr/Article/E0001152)으로 교차 확인.

### 사건 및 권한 처리
- 11호의 미확인 본권 출처를 새로 만들어 붙이지 않는다. 표시 페이지는 반드시 `11호 워크북 … (본권 아님)`.
- 학습 주제 구분 `period: goryeo`, `nation: 고려|거란`을 사용하여 나라를 혼동하지 않는다.
- 거란 인물 `소배압`은 기존 고려 시기 사건 설명에 이미 이름이 있으므로 사건의 연도나 문장을 새로 만들 필요가 없다.
- 학생별 공개는 `getHistoryTimelineTopicsForIssues`와 기존 이수 권한으로 필터링한다.
- `scripts/check-history-people.cjs`에서 네 인물 연결, 소속 구분, 11호 비허용 시 미노출을 검사한다.
- 기존 학생 계정·수강 정보·진도·문제은행 데이터베이스는 수정하지 않는다.

## 2026-11-16 이어서 대조하면서 재확인한 사항
- 현재 운영 브랜치에는 13호 25쪽의 이원·주원장 인물카드 및 4호 고연무·담징이 이미 존재한다. **중복 등록하지 않는다**.
- `3호.pdf`, `3호 (1).pdf`는 각각 고구려 벽화 부채 만들기·광개토대왕릉비 만들기 활동지 2쪽이다. **3호 본권 확보로 표시하지 않는다**.
- 여전히 **03·08·09·11·14~23호 본권**이 확인되지 않았다. 현재 구할 수 있는 워크북/활동지/타 교재는 원본 본권 대조를 대신하지 않는다.
