## 4. 검증·공개 원칙

- 기존 핵심 사건과 학생 데이터·진도·한능검 연결 파일은 그대로 유지한다.
- 새 카드 14개는 보충자료 접근이 허용된 계정에만 별도 API로 제공한다. 학생이 항상 자동으로 본다는 뜻은 아니다.
- 체크박스 「✅ 누락 검증 추가 사건」에서 14개 사건을 보이기·숨기기 한다.
- 기존 사건과 같은 연도·제목이면 기존 사건이 우선하여 보충 카드는 중복 표시하지 않는다.
- 1948년 4월의 제주4·3은 대한민국 정부 수립(8.15) 전 사건이므로 '광복과 분단의 시작' 시대로 구분한다.
- 동일 연도의 사건은 `sortOrder`를 사용해 연대순 표시를 돕는다.
- 각 카드 출처는 저작권 보호를 위해 원문 재현 없이 책·PDF 쪽수만 표시한다.

## 5. 1차 단계의 남은 정밀성 검증

이번 작업은 **참고문헌 연표·장 도입부의 전 시대 주요 사건을 대상으로 한 1차 대조와 확인 누락 보완**이다. 그러나 전권 모든 페이지에서 세부 사건을 독립적으로 추출한 것은 아니다. 원본 모든 페이지/사건 항목을 검토 완료 처리한 체크리스트도 아직 없다.

따라서 **'1차 주요 연표 보강 완료'는 가능하지만, '1차 사건·연도 전권 누락 검증 100% 완료'라고는 판정할 수 없다**. 전권 완전성을 판정하려면 모든 페이지에 검토 상태와 사건 ID가 연결된 감사표가 필요하다.

후속 단계: 2차 인물·제도·문화·사료, 3차 인과관계, 4차 재검수. 4회로 누락 0건을 보장하지 않는다.
