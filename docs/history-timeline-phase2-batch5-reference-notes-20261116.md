# 한국사 연표 — 2차 참고문헌 검증 5번째 보강 (2026-11-16)

## 범위와 분류 원칙
Sun Lab `/history/timeline`의 이전 2차 검증을 이어서 실제 업로드 참고서 PDF 지면과 기존 사건을 대조했다. 이 작업은 8권 전수 검증이 아니라 **5개 설명 추가와 별별한국사 초등 출처 분류**에 한정한다. 새 역사 사건의 날짜나 사건 ID를 임의로 만들지 않았고, 책 문장을 복제하지 않았다.

기존 PR #183은 `closed / unmerged`였지만, 4건 설명에 해당하는 `lib/historyTimelinePhaseTwoBatchThreeNotes.ts`와 해당 집계 코드가 2026-11-16 기준 운영 `main`에 들어가 있고 Production 커밋 `2cae8084...`로 READY인 것을 확인했다. 중복 작성하지 않는다. 이전 4차 보강 5건 역시 운영 코드에 존재한다.

## 실제 코드 작업
1. `lib/historyTimelinePhaseTwoReadingNotes.ts`: 로빈 1·읽기책 2·초등 2, 총 5건 출처/쪽수와 학습용 설명 추가.
2. `lib/historyTimelineReferenceGroups.ts`: `elementary` 출처 그룹 정의. 초등 책을 다른 참고서 출처로 잘못 분류하지 않는다.
3. `app/history/timeline/TimelineReferenceNotes.tsx`: 참고문헌별 보충 설명 표시 시 `elementary` 조건 추가.
4. `app/history/timeline/TimelineClient.tsx`: `별별한국사 · 초등` 보기 체크박스 추가 및 교사/학생의 기본 표시값을 기존 보충자료 방식과 동일하게 적용.
5. 학생별 기존 수강 완료 호수 및 보충자료 접근권한은 `/api/history/timeline/byeolbyeol`의 서버 측 검증을 그대로 사용. 해당 API와 보안·세션 코드는 수정하지 않는다.
