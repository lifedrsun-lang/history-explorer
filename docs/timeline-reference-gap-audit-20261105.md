## 중복 방지
- 기존 일반 연표(문화유산 사건 포함)에 **같은 연도·같은 제목** 카드가 표시되는 경우 별별·용선생 전용 카드를 추가로 출력하지 않음.
- 실례: 고려의 1232년 강화도 천도 사건.
- 이 보정은 화면 표시 중복만 방지하며 기존 사건 저장 데이터는 변경하지 않는다.

## 미완료 사항과 추후 4회차 원칙
1. **시대별 주요 사건 대조**: 8권의 각 장·연표 페이지를 전 시대에 걸쳐 비교한다.
2. **인물·제도·사료·문화유산 보강**: 본문과 각주·사진 캡션을 세부 항목으로 분류하여 기존 카드에 넣거나 새 카드로 생성한다.
3. **인과관계 및 출처 정합성**: 연대, 왕명, 제도, 결과, 참고문헌 지면과 연결된 사건 ID를 교차 검사한다.
4. **전권 재검수 및 실제 화면 검증**: 각 페이지/항목 처리상태를 확인하고 교사·학생 권한, 중복과 모바일 표시를 검사한다.

**4회차는 권장 작업 구조이지, 그 횟수만으로 누락 0건을 보장하는 수치가 아니다.** 남은 검증 대상의 처리 미완료 건수가 0이고, 최종 2회 연속 새로운 누락이 발견되지 않으면 종료 검토에 들어간다.
