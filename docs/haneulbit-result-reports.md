# 하늘빛초 결과통지서 구현 및 검증 현황

## 구현

학교 관리 → 하늘빛초 화면 안의 `결과통지서` 카드 → `/teacher/after-school/haneulbit/reports`.

기존 `students` 컬렉션, `toStudentRosterRecord`, 학교 별칭 비교, 교사 Firebase 인증 API, Chromium/Puppeteer 및 기존 한글 폰트를 재사용한다. 학생 컬렉션에는 쓰지 않는다. 수강중 하늘빛초 학생만 기본 목록에 표시하고, 현재 학년·반·이름을 30초 간격 및 창 복귀 시 갱신한다. `schoolClass` 필드를 먼저 쓰고 기존 `className`/`class` 필드로 대체한다.

4개 항목의 5단계 평가를 같은 화면에서 라디오 버튼으로 입력한다. 항목별 전체 적용은 현재 수강생을 대상으로 하며, 개별 수정값을 덮어쓴다는 확인 메시지를 표시한다. 종합의견은 직접 입력하고 자동 생성하지 않는다. 문구 기능은 `ReportEvaluation.comment`에 선택 문구를 넣는 방식으로 추후 연결할 수 있으며 이번 작업에서는 임의 문구를 추가하지 않는다.

`haneulbit_result_reports/{year}-Q{quarter}`에 공통 정보와 revision을 저장하고, `evaluations/{studentId}`에 평가 및 출력 당시 학생 정보를 저장한다. 저장 요청은 변경된 행만 보낸다. 저장 트랜잭션에서 revision을 검사하여 다른 창의 변경사항을 덮어쓰지 않는다. 이전 분기 복사는 새 분기에 학습 활동 내용과 지도강사명만 복사하고 평가값은 복사하지 않는다.

현재 학생 정보가 변경되면 화면에 현재 값을 표시하고 저장된 출력 정보도 함께 보여준다. `현재 학생 정보 반영`으로 새 정보를 저장한 뒤 출력한다. 수강 종료·학생 삭제 이후에도 이미 저장된 기록은 보존되며 `과거 수강생 기록 함께 보기`로 열 수 있다.

작성완료 조건: 공통 교육기간·학습 활동·강사명, 학생 학년·반·이름, 네 평가와 직접 입력한 종합의견 모두 존재. 평가와 의견이 전혀 없으면 미작성, 그 외 필수값이 부족하면 작성중이다. 별도 미완료 필터는 미작성과 작성중을 포함한다.

PDF API는 저장된 revision의 자료만 출력한다. 출력 전 변경사항 저장이 필요하다. 개별 미리보기는 인증된 POST로 받은 PDF Blob을 dialog/iframe에서 표시한다. 전체 다운로드는 선택한 현재/과거 학생 중 작성완료 학생의 PDF를 UTF-8 ZIP으로 묶는다. 동명이인 파일명 충돌은 학년·반과 순번을 추가해 해결한다. BAND, 메일, 공유 연동은 추가하지 않았다.

## 아직 완료할 수 없는 부분

- 지정된 원본 HWPX 파일은 이 작업에 첨부되지 않았고, 접근 가능한 파일 검색·목록에서도 확인되지 않았다.
- 따라서 `templates/haneulbit/result-report.html`을 임의로 만들지 않았다. 현재 PDF API는 503을 반환하고 화면은 PDF 버튼을 비활성화한다. 원본의 문구·표 구조·체크 좌표를 적용해야 실제 출력 기능이 완성된다. 템플릿 계약은 해당 디렉터리 README에 있다.
- 운영 Sun Lab 브라우저는 교사 로그인이 없는 상태다. 실제 하늘빛초 수강생과 운영 DB 저장·새로고침 유지, 학교 원본 PDF 일치 여부는 확인되지 않았다.
- 운영 배포는 하지 않았다. 이 변경은 원본 양식 적용과 운영 검증을 기다리는 검토용 구현이다.

## 수행한 검증

- `npx tsc --noEmit`: 통과.
- 변경된 TS/TSX/API 파일 대상 ESLint: 통과.
- `npm run build`: 전체 Next.js 프로덕션 빌드 통과. 제한된 네트워크에서 기존 Google 글꼴 다운로드가 실패한 최초 실행 이후, 네트워크가 허용된 환경에서 통과.
- `node scripts/verify-haneulbit-reports.cjs`: 격리된 메모리 저장소로 학교·수강상태 필터, 학년·반·이름 매핑, 필수값/상태, 저장·재조회, revision 충돌, 분기 보존, 학생 변경·종료 후 과거 기록 보존, 학생 컬렉션 쓰기 없음, 동명이인 ZIP 및 한글 이름 검증 통과.
- 위 스크립트의 **시험용 양식**으로 실제 Chromium PDF 생성, 한글 텍스트 추출, 평가 체크 4개, A4 1페이지, 긴 의견의 영역 초과 거부 검증 통과. 학교 원본의 디자인·체크 위치 검증을 대체하지 않는다.

## 요청한 14개 항목의 상태

| 항목 | 현재 근거 | 남은 검증 |
|---|---|---|
| 카드 표시 | 빌드 경로 생성·학교 페이지 코드 | 로그인된 브라우저 표시 |
| 카드 이동 | 링크·새 경로 빌드 | 실제 클릭 |
| 실제 수강생 자동 표시 | 기존 학생 컬렉션 조회 연결·시험 데이터 통과 | 운영 수강생 조회 |
| 학년·반·이름 연결 | 기존 변환 함수 재사용·시험 데이터 통과 | 운영 값 대조 |
| 저장 후 새로고침 유지 | 메모리 저장소의 저장·재조회 통과 | 운영 DB + 브라우저 새로고침 |
| 작성 상태 | 필수값·상태 테스트 통과 | 실제 화면 입력 |
| PDF 미리보기 | POST/Blob/dialog 연결 코드 | 원본 적용 후 클릭 |
| 원본 양식 일치 | 확인 불가 | 원본 HWPX 필요 |
| 한글 출력 | 시험용 PDF 추출 통과 | 원본 PDF 시각 검사 |
| 체크 위치 | 시험용 PDF 체크 개수 통과 | 원본 좌표 대조 |
| 종합의견 영역 | 시험용 PDF 영역 초과 거부 통과 | 원본 텍스트 영역 대조 |
| 개별 다운로드 | PDF API·파일명 생성 구현 | 원본 적용 후 브라우저 다운로드 |
| 전체 다운로드 | 실제 ZIP 해제·한글 파일명·중복 방지 통과 | 원본 적용 후 일괄 다운로드 |
| 과거 분기 유지 | 분리된 기록·시험 저장소 검증 통과 | 운영 분기 전환·재조회 |
